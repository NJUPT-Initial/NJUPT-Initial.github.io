// 01 OVERVIEW

一支把想法做成机器的队伍

NJUPT Initial 是来自南京邮电大学的学生机器人团队。 我们不满足于纸面方案——从机构设计、电控联调到运控算法，每一条链路都要在实机上闭环验证。

// 02 DISCIPLINES

三条技术主链

跨专业协作不是口号——机械、电控、算法在同一台机器人上对齐接口与验收标准。

01 · 机械设计
机构设计、建模仿真与加工装配。负责腿系自由度布局、轮足复合驱动、整机结构与可维护性。
02 · 电控与嵌入式
硬件设计、驱动控制与系统联调。STM32 实时固件、CAN 执行器网络、遥控与上位机链路、安全状态机。
03 · 算法与感知
环境感知、定位规划与智能决策。步态与足端轨迹、障碍状态机、上位机遥测与调试工具链。

// 03 FLAGSHIP · RC-DOG

8 自由度轮足四足固件

26Initial-RC-dog 是赛季主控固件：统一 LibXR 硬件抽象与 XRobot 模块框架， 以可生成入口替代手工漂移，把输入仲裁、安全锁存与电机保护收拢到清晰边界。

关节执行

8 × 海泰 HWG7015-J8 + 守护兽驱动板

FDCAN1 / FDCAN2 · 8:1

轮组执行

4 × M3508 + 减速箱 + C620 电调

FDCAN3 · 268/17

主控制系统

达妙 DM MC-02（STM32H723）

FreeRTOS · C++20

链路

SBUS 遥控 + XRUSB CDC 上位机

Topic · CRC 校验

安全架构要点

  • S1上电默认安全锁存；无新鲜 SBUS 不允许运动
  • S2CH9 实体急停最高优先级，锁腿锁轮
  • S3SBUS 250 ms / USB 150 ms 看门狗与会话零命令
  • S4轮电机 70 °C 降额 · 85 °C 切断 · 峰值电流预算
  • S5腿/轮反馈超时与 CAN bus-off 进入故障态

源码与完整协议文档见 NJUPT-Initial/26Initial-RC-dog （MIT）。早期框架曾参考辽宁科技大学 COD 开源模板，后迁移到维护更完善的 XRobot/LibXR。
