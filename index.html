// 02 你能学到什么

三条路，选一条或都试试

LEARN

不用一开始就很厉害。我们会从基础带起，边做项目边学。

A 机械设计

画图、建模、加工、装配。把脑子里的结构变成能转、能扛、能装进电机的零件。

  • 三维建模
  • 加工装配
  • 整机结构
B 电控与嵌入式

写单片机代码、接电机、调遥控。让硬件按你的指令动起来，学会排查真实故障。

  • STM32
  • 电机控制
  • 通信调试
C 算法与感知

让机器人走得稳、走得聪明：步态、轨迹、上位机可视化，以及后续感知与规划。

  • 运动控制
  • 上位机
  • 智能决策

// 04 常见问题

新生最常问的几件事

FAQ
  • Q1没学过机器人 / 不会写代码，能来吗？能。很多队友是进来才开始学的，我们按方向带基础。
  • Q2大一课很多，会不会冲突？会协调时间，以项目推进为主；愿意花时间比“已经很牛”更重要。
  • Q3只能做硬件 / 只想写软件吗？可以。三条主链都能深挖，也可以中途换方向试试。
  • Q4怎么联系你们？在 GitHub 开 Issue，或关注组织仓库；线下招新见学院通知。
