# NJUPT Initial

南京邮电大学 Robocon Initial 战队 **招新页**（GitHub Pages）。

- 线上地址（推送并开启 Pages 后）：https://njupt-initial.github.io
- 受众：新生 / 感兴趣的同学；内容偏招新，不堆技术细节
- 纯静态：`index.html` + `styles.css` + `main.js`
- 本地预览：`python -m http.server 8080` 后打开 http://localhost:8080

## 部署

1. 推送到组织仓库 `NJUPT-Initial/NJUPT-Initial.github.io`
2. Settings → Pages → Deploy from a branch → `main` / `(root)`
3. 访问 https://njupt-initial.github.io
